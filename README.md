# VIZZ

Portfolio site for VIZZ: AI video commercials, brand films and motion.

Plain HTML, no build step. Hosted on Cloudflare Pages: every push to `main` goes live automatically.

## Adding work

Projects live in the `projects` list near the bottom of `index.html`. Each project takes a title,
client, type, year, a short "about" text, a list of Vimeo video IDs (shown as No. 01, No. 02, ...)
and a cover image URL.

## Fonts

- Rubik Black (placeholder for the name), Instrument Serif: both SIL Open Font License, served from `fonts/`.
